# bool

`true` or `false`. A `bool` is never used as a number, but it can be converted to one on purpose.

## Converting

| Method | Returns | Description |
|--------|---------|-------------|
| `toNumber()` | `number` | `1` for `true`, `0` for `false` |
| `toString()` | `string` | `'true'` or `'false'` |
